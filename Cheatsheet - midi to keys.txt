This is for the midi-to-keys script, currently in the midi-to-keys directory on the desktop.

First the xdotool needs to be installed: https://github.com/jordansissel/xdotool, https://superuser.com/questions/1170136/translating-midi-input-into-computer-keystrokes-on-linux

apt-get install xdotool

PLEASE NOTE: xdotool ONLY works in X11, not Wayland!!!

For Wayland alternatives for xdotool see: https://www.reddit.com/r/linuxquestions/comments/u5mxzi/xdotool_alternative_for_wayland/ or use your google fu
To list the midi controllers connected:

aseqdump -l


Output will look something like this:

To see what midi keys are being pressed from the SMC-Pad Pocket:

aseqdump -p "SINCO"

 To change what each key does edit the midi-to-keys file:
 
 micro ./midi-to-keys
 
 It will look something like this:
 
# Source - https://superuser.com/a/1170232
# Posted by CL., modified by community. See post 'Timeline' for change history
# Retrieved 2026-05-14, License - CC BY-SA 3.0
 
 #!/bin/bash
aseqdump -p "SINCO" | \
while IFS=" ," read src ev1 ev2 ch label1 data1 label2 data2 rest; do
    case "$ev1 $ev2 $data1" in
        "Note on 64" ) xdotool type hello ;;
        #"Note on 48" ) xdotool key ctrl+j ;;
	"Note on 48" ) xdotool exec /usr/bin/firefox ;;
	#"Note on 49" ) xdotoaaol exec google-chrome ;;
	#"Note on 49" ) xdotool exec google-chrome www.askubuntu.com ;;
	"Note on 49" ) xdotool exec google-chrome  https://mail.google.com/mail/u/0/#inbox?compose=new 
    esac
done
